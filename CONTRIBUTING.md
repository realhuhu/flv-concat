# Contributing

Bug reports and focused pull requests are welcome.

Before opening a change:

1. Search existing issues.
2. Keep sample recordings private unless you have permission to share them.
3. Describe the recorder or streaming software, expected duration, observed duration, and the exact command.
4. For code changes, build with warnings enabled and run \`ctest --test-dir build --output-on-failure\`.
5. Add a synthetic regression fixture or unit test whenever practical. Do not commit large or copyrighted recordings.

By contributing, you agree that your contribution is licensed under GPL-3.0-only.
